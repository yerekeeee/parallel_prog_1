Пример-6: Поиск максимума в огромном массиве

Описание: Поиск самого большого числа в массиве данных. Вместо того чтобы один процесс перебирал миллионы чисел, массив "нарезается" на куски с помощью MPI_Scatter. Каждый процесс находит локальный максимум, а затем MPI_Reduce с оператором MPI_MAX находит глобальный.
