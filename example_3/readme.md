Пример-3. Распределение задач "Мастер-Воркер" (Рендеринг CGI, Матрицы ИИ)

Суть: Главный процесс (Мастер) имеет огромный массив данных (например, пустую картинку 4K или огромные матрицы). Он "раскидывает" куски данных (MPI_Scatter) остальным узлам. Узлы считают цвет своих пикселей или умножают свои строки матрицы, а потом Мастер "собирает" (MPI_Gather) их обратно в готовый файл.
