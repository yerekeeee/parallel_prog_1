# 🚀 Параллельное программирование (MPI) — Сборник задач

В данном проекте представлены практические примеры решения задач с использованием технологии параллельных вычислений **MPI (Message Passing Interface)** на языке C++. Проект подготовлен в рамках лабораторных работ / рубежного контроля.

---

## 📂 Структура проекта

Проект разбит на 6 независимых директорий. Каждая папка — это отдельная задача со своим исходным кодом и инструкцией.

```text
parallel_prog_1/
├── example_1/           # Задача 1: Программа "Ping-Pong" (Передача сообщений)
│   ├── main.cpp         # Исходный код на C++
│   ├── readme.md        # Описание конкретной задачи
│   └── run              # Исполняемый файл (появляется после компиляции)
├── example_2/           # Задача 2: Вычисление числа Пи (Численное интегрирование)
├── example_3/           # Задача 3: Умножение матрицы на вектор
├── example_4/           # Задача 4: Поиск максимума в массиве (Scatter/Reduce)
├── example_5/           # Задача 5: Вычисление факториала большого числа
└── example_6/           # Задача 6: Пользовательская задача
```

## 🛠 Требования к окружению (Установка)

Для компиляции и запуска программ на вашем компьютере должна быть установлена библиотека **OpenMPI**.

### Для macOS (через Homebrew)
Откройте Терминал и выполните команду:
```bash
brew install open-mpi
```

### Для Linux (Ubuntu / Debian)
```bash
sudo apt-get update
sudo apt-get install openmpi-bin libopenmpi-dev
```

> **Примечание:** Если вы работаете на учебном сервере кластера, установка не требуется. Перед началом работы просто загрузите модуль MPI командой:
> ```bash
> module load mpi
> ```

## 💻 Инструкция: от компиляции до запуска

Все действия выполняются через системный Терминал. Ниже приведена универсальная инструкция на примере первой задачи (`example_1`).

### Шаг 1: Переход в директорию
Откройте терминал и перейдите в папку с нужным примером:
```bash
cd example_1
```

### Шаг 2: Компиляция исходного кода
Для сборки MPI-программы используется компилятор `mpicxx` (обертка над стандартным `g++`). 

Выполните команду сборки:
```bash
mpicxx main.cpp -o run
```
*Если в коде нет ошибок, команда отработает без вывода текста, и в папке появится готовый файл `run`.*

### Шаг 3: Запуск программы
Запуск осуществляется через утилиту `mpirun`. Флаг `-np` *(number of processes)* указывает, на сколько параллельных потоков нужно разбить вычисления.

Запуск на **4 параллельных потоках**:
```bash
mpirun -np 4 ./run
```

## ⚠️ Решение частых проблем

* **Ошибка `unsupported mach-o filetype` при компиляции**  
  Вы случайно передали компилятору уже собранный файл. Убедитесь, что вы компилируете именно `.cpp` файл. Правильно: `mpicxx main.cpp -o run`.

* **Ошибка `Permission denied` при запуске**  
  ОС заблокировала запуск файла. Выдайте файлу права на исполнение:
  ```bash
  chmod +x run
  ```
  После этого повторите команду запуска.

* **Запуск на суперкомпьютерах (SLURM / PBS)**  
  На некоторых серверах прямой запуск через `mpirun` запрещен, чтобы не перегружать головной узел. В таких случаях используйте менеджер очередей:
  ```bash
  srun -n 4 ./run
  ```
